# CausalInvariantFlow research package

This package contains the complete research design for a paper on **Calibrated Physics-Constrained Flow Matching for Rare-Event Forecasting in Chaotic Dynamical Systems under Known Interventions**.

## What is complete now

- Literature-grounded research gap and novelty boundary.
- Formal problem definition and proposed model.
- Preregistered benchmark and metric protocol.
- Manuscript draft with explicit placeholders for results that must be generated by experiments.
- Reproducible Python starter code for data generation and deterministic baselines.

## What is not claimed

No empirical result is claimed until the experiment scripts are run and the generated artifacts are inspected. The project uses “known interventions” rather than causal discovery. The term “physics-constrained” means solver-verified residuals/projection or explicitly reported soft residual penalties; it does not imply exact invariant preservation by a neural network.

## Research question

Can a conditional flow-matching model generate calibrated distributions of future trajectories for chaotic systems, preserve known dynamical structure, and forecast rare-event paths under parameter/forcing interventions better than strong non-generative and generative baselines at matched simulator cost?

## Recommended execution order

1. Run the Lorenz-63 sanity benchmark and all deterministic baselines.
2. Add conditional flow matching and verify training on held-out initial states.
3. Add physics residual/projection and compare constraint validity versus tail fidelity.
4. Add calibration and rare-event metrics.
5. Run Lorenz-96 or Kuramoto–Sivashinsky as the spatiotemporal stress test.
6. Add active simulation selection only as a secondary, budgeted experiment.
7. Replace all result placeholders in the manuscript only from committed result files.

## Files

- `research_proposal.md`: full proposal and contribution boundary.
- `manuscript_draft.md`: paper-ready structure with methods and results placeholders.
- `experiment_protocol.md`: preregistered experiments, splits, metrics, ablations, and stopping rules.
- `src/generate_lorenz.py`: deterministic Lorenz-63 data generation.
- `src/metrics.py`: core forecast, calibration, and rare-event metrics.
- `requirements.txt`: minimal starter dependencies.
# Extended implementation files

- `src/flow_matching.py`: conditional vector field, flow-matching loss, and Euler sampler.
- `src/run_experiment.py`: dataset windows, training loop, and checkpoint writer.
- `tests/lorenz_smoke.js`: runtime-independent simulator smoke test.

The Python model requires PyTorch. The current device exposes a Windows Store Python launcher that returns Access Denied, so the model training command is intentionally not marked as executed until a functioning Python environment is available.
