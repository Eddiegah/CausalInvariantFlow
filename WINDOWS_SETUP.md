# Windows Python and PyTorch setup

## Diagnosis

This device currently resolves `py` to a Microsoft Store Python 3.13 package under `C:\Program Files\WindowsApps`, but launching that executable returns `Access is denied`. There is no normal `python.exe` on `PATH`. Chocolatey cannot write to its system installation roots from this session, and direct downloads fail during TLS negotiation with `SEC_E_NO_CREDENTIALS`.

## Recommended repair

1. Open **Settings → Apps → Advanced app settings → App execution aliases**.
2. Turn **off** the aliases named `python.exe` and `python3.exe` if they point to the Microsoft Store.
3. Install **CPython 3.11 or 3.12, 64-bit** from <https://www.python.org/downloads/windows/> using the per-user option.
4. Select **Add python.exe to PATH** and **pip** in the installer.
5. Open a new PowerShell window and verify:

```powershell
python --version
python -c "import sys; print(sys.executable)"
python -m pip --version
```

6. Create the project environment:

```powershell
cd C:\Users\gahed\OneDrive\Documents\Manus\2026-10-05\aT0Mik\outputs\causalinvariantflow
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip setuptools wheel
```

If activation is blocked, use `.\.venv\Scripts\python.exe` directly.

## Install PyTorch

CPU-only:

```powershell
python -m pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements.txt
```

For NVIDIA CUDA, use the command generated by <https://pytorch.org/get-started/locally/> and then run `python -m pip install -r requirements.txt`.

Verify:

```powershell
python -c "import torch; print(torch.__version__); print('cuda=', torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"
```

Paper-grade runs still require the protocol additions in `experiment_protocol.md`: independent splits, solver verification, physics residuals/projection, intervention conditioning, rare-event metrics, repeated seeds, and saved result manifests.

## If downloads are blocked

Use a user-controlled browser to download the official installer. This device's command-line TLS layer cannot establish the Python.org connection. If corporate policy blocks Python.org, ask IT to provide a managed CPython 3.11/3.12 installation or allow the official distribution. Do not bypass Windows ACLs or Store permissions.
